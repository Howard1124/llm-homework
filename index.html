🤖 LLM 新聞摘要小程式

學生資訊：資管系學生作業作品頁

1. 這個專案做了什麼？

本程式使用 Python 呼叫 Google Gemini API（gemini-2.5-flash 模型），針對指定的科技新聞內容進行自動重點摘要，並採用串流輸出（Streaming）技術，讓使用者能即時看到 AI 生成文字的過程。

2. 如何執行？

確保安裝 Python 與 uv 套件管理工具後，依照以下步驟執行：

# 1. 設定環境變數（填入你的 Gemini API Key）
export GEMINI_API_KEY="你的-api-key"

# 2. 執行主程式
python main.py

3. 執行結果

程式會自動讀取內建的新聞文本，並即時串流輸出 3 個核心要點與總結內容。

4. AI 使用與修改說明

本專案在開發過程中透過 AI 協作完成程式架構設計、Gemini API 串流語法除錯，並確保符合專案規格，同時嚴格遵守 .gitignore 規範以防止 API 金鑰外洩。
