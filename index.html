🤖 LLM 新聞摘要小程式

Advanced AI News Summarizer & Streaming Pipeline
Python 3.10+ Gemini API Streaming Output uv Manager GitHub Actions

⚡ 1. 專案核心功能與架構

本專案實作了一支高效能的 AI 新聞自動化摘要系統，透過 Python 深度調用 Google Gemini API (gemini-2.5-flash) 進行長文本語意分析。

  • 即時串流機制 (Streaming)：採用 generate_content_stream 實現低延遲的逐字輸出體驗。
  • 現代依賴管理：全面整合 uv 套件管理器，確保建置過程高速且乾淨。
  • 企業級資安防護：嚴格落實 .env 與 .gitignore 隔離，滴水不漏保護 API 金鑰。

🚀 2. 本地執行與部署指令

如需在本地端還原並執行本專案，請參考以下標準命令：

bash — zsh
# 1. 設定 API 金鑰環境變數
export GEMINI_API_KEY="your-api-key-here"

# 2. 使用 uv 執行主程式
uv run main.py

💡 4. AI 協作與開發心得

  • 架構規畫：在開發階段借助 AI 進行模組化設計與 SDK 語法除錯。
  • 驗證優化：針對非同步串流輸出的邊界條件進行反覆測試與效能調校。
  • 自動化整合：透過 GitHub Actions Workflow 確保每次提交皆能自動編譯並部署至 Pages。
