1. 這個專案做了什麼？

本專案是一支基於 Python 開發的 AI 新聞自動化摘要工具，調用 Google Gemini API (gemini-2.5-flash 模型) 對長篇科技新聞內容進行結構化分析與核心要點擷取。

核心技術亮點：

  • Streaming 串流輸出：採用 generate_content_stream 方法，實現打字機般的即時文字生成體驗。
  • 現代化環境管理：使用高效能 uv 套件管理器構建依賴環境。
  • 資安防護機制：落實 .env 環境變數隔離與 .gitignore 規則，防止 API Key 上傳外洩。

2. 如何執行專案？

確保本地或雲端環境具備 Python 3.10+ 與依賴套件後，依照以下指令步驟執行：

Terminal / Bash
# Step 1. 設定 Gemini API Key 環境變數
export GEMINI_API_KEY="your-gemini-api-key-here"

# Step 2. 使用 uv 執行主程式（自動下載依賴並運行）
uv run main.py
